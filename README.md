# مدرك: أين تحتاج الخدمات غير الربحية دعماً أكثر؟

**هاكثون تحليل البيانات في القطاع غير الربحي 2** · ملتقى تحليل البيانات · جمعية كفاءات الأهلية

مدرك أداة تحليل ووكيل ذكاء اصطناعي يجيبان عن سؤال واحد يطرحه الممول وصانع القرار:
**في أي منطقة، وفي أي تخصص، يقل عدد الجمعيات الأهلية عن حاجة السكان؟ وأين يذهب الدعم الجديد بأكبر فائدة؟**

يبدأ من الملفات الخام المفتوحة، ويُنظّفها ويوثّق كل تعديل، ثم يحسب الجمعيات لكل 100 ألف نسمة لكل منطقة وتخصص، ويبني **مصفوفة قرار** و**تقريراً تفاعلياً** بأمر واحد. ويتوقف ليسأل الإنسان قبل أي قرار.

> **ابدأ من هنا:** افتح `outputs/report.html` (تقرير تفاعلي، يعمل دون إنترنت) أو `outputs/report.pdf`.
>
> **شغّله بنفسك في Google Colab:** [analysis.ipynb](https://colab.research.google.com/github/hessahalturkiworks/mudrik/blob/main/analysis.ipynb) ← من القائمة `Runtime` اختر `Run all`. يعيد الدفتر كل شيء من الملفات الخام، ويتوقف لموافقة الإنسان، ثم يتحقق أن الأرقام مطابقة للتقرير.

## مدرك على بيانات أخرى

الوكيل نفسه، **دون تعديل في كود الحساب**، طُبّق على ملفات مختلفة من المنصة الوطنية للبيانات المفتوحة. كل مثال له إعداداته وقرارات صاحبة المشروع في `agent_tests/` (التفاصيل في `agent_tests/AGENT_TEST_LOG.md`). هذه أمثلة مستقلة، ولا تدخل في أرقام التقرير الرئيسي.

## التشغيل

**المتطلبات:** Python 3.10 أو أحدث.

```bash
pip install -r requirements.txt
python -m playwright install chromium
```
(Chromium لتحويل الرسوم والتقرير إلى PNG وPDF بعربية صحيحة. بدونه تُنتَج ملفات HTML فقط.)

**التشغيل الكامل من الملفات الخام** (من المجلد الرئيسي):

```bash
python scripts/run_pipeline.py          # ١) ينظّف، ثم يعرض القرارات ويتوقف
python scripts/run_pipeline.py --yes    # ٢) بعد موافقة الإنسان: تحليل + طلب + 2030 + تقرير
```

الخطوة الأولى تتوقف عمداً وتطبع القرارات الحالية من `scripts/config.json`. لا يُحسب شيء قبل الموافقة. `--skip-clean` يتخطى التنظيف إن كانت `data_clean/` جاهزة.

**الحد الأدنى:** ملف الكيانات + جدول السكان. أي ملف آخر ناقص يُتخطى قسمه، ويكتب التقرير «غير متوفر».

**إعادة التشغيل:** تشغيل الأمر مرتين يعطي جداول **مطابقة بايت ببايت**.

## المنهجية باختصار

1. **التنظيف** (`prompts/cleaning.md`): الأصل لا يُلمس، لا أعمدة جديدة، المجهول «غير محدد» دون تخمين، الحذف للمكرر تماماً فقط، وكل تعديل مسجل (الصف، العمود، قبل، بعد، السبب). الجمعيات: 1,021 خلية مصححة و37 حالة للمراجعة اليدوية. المؤسسات: حُذف صف مكرر واحد.
2. **المعدل:** جمعيات كل منطقة وتخصص ÷ سكانها × 100 ألف، ثم **المؤشر** = معدل المنطقة ÷ المتوسط الوطني للتخصص.
3. **مصفوفة القرار:** المؤشر < 0.5 «أولوية دعم»، و≥ 1.5 «تغطية عالية»، وما بينهما «تغطية مناسبة». الخانة بأقل من 3 جمعيات (أو تخصص وطني أقل من 30) تُوسم «أرقام قليلة».
4. **عدسة الطلب:** ضغط التخصص = حصته من المستفيدين ÷ حصته من المنشآت (مسح 2018). تعيد ترتيب خانات «أولوية دعم» ولا تغيّر التوصية.
5. **فجوة 2030:** توقع سكان كل منطقة بطريقتين، واختيار الأقل خطأً في **اختبار رجعي بلا تسريب** (تدريب 2010–2018 وتوقع 2022): النمو السنوي المركّب بخطأ 4.4% مقابل 7.8% للاتجاه الخطي.
6. **القرارات البشرية** (في `scripts/config.json` وموثقة في `outputs/analysis_decisions_log.csv`): استبعاد الكيانين الوطنيين (2)، واستبعاد غير المصنف والمنشأة بأمر ملكي (121)، والمؤسسات طبقة داعمة خارج المعدل (384)، والعتبات أعلاه.

## حدود التحليل

- المؤشر **عدد الجمعيات المسجلة**، وليس حجم الخدمة أو أثرها على المستفيدين. مدرك لا يقيس الأثر لعدم توفر بيانات النتائج.
- المنطقة هي **منطقة التسجيل**، وقد تخدم الجمعية مناطق أخرى.
- ملفان رسميان قد يختلفان: ملف منطقة الرياض فيه 872 جمعية مقابل 961 في الملف الوطني (≈9%). النتائج **مؤشرات** وليست عدّاً نهائياً.
- مسح 2018 **وطني** بلا مناطق، ويشمل كل المنشآت غير الربحية.
- فجوة 2030 **سيناريو** بمعيار المتوسط الوطني الحالي، والطريقة بالغت قليلاً في الاختبار الرجعي فأرقامها أقرب إلى حد أعلى.

## الذكاء الاصطناعي المسؤول

- **الذكاء يقترح، والإنسان يقرر:** الخط يتوقف قبل التحليل حتى توافق صاحبة المشروع على القرارات.
- **لا تخمين:** عند بيانات لا تصلح (منطقة واحدة، مدن بلا سكان، أعمدة ناقصة) يتوقف الوكيل برسالة واضحة بدل اختراع نتيجة. أمثلة في `agent_tests/AGENT_TEST_LOG.md`.
- **كل رقم من الكود:** الملخص والتقرير يقرآن من `outputs/` فقط، والسجلات تثبت مصدر كل رقم.
- سجل استخدام الذكاء الاصطناعي: `ai_usage_log.md`.
